# TinyTry · 自律搭子

中文、手机优先的静态 H5。通过预设选择，找到这一次卡住的原因，尝试小动作，再根据反馈调整。完整覆盖睡眠、饮食、运动、玩耍和拖延。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm ci
npm run dev -- --port 4173
```

浏览器打开 http://localhost:4173 。停止服务使用 Ctrl+C。

```sh
npm test
npm run build
npm run preview -- --port 4173
```

`dist/` 是静态构建产物，可以由任何普通静态服务器提供。使用 Hash 路由及相对资源路径，不需要服务器路由重写。不建议直接双击 HTML：浏览器可能限制脚本及本地存储。

## 使用闭环

1. 在首页选择场景，或从“帮我复盘一下”进入事后回顾。
2. 选择情境、确认原因、选择办法，并确认行动。此时生成待验证记录。
3. 有时长的行动可启动倒计时；刷新后继续按实际截止时间计算，不提供后台通知。
4. 首页优先提醒最近一条待验证记录；“我的记录”可反馈其他记录。
5. 点击“验证效果”，选择“好像没什么用 / 有点意思 / 很有效！”，立即保存。调整办法是后续可选步骤；“其实还没试”作为独立选项，不计入效果验证。
6. 预设方法不合适时可创建自己的方法（1–120 字，可选 1–180 分钟计时）。保存后即在“我的方法 → 我创建的”可见，确认行动后才创建待验证尝试。
7. 同一自建方法的三个独立尝试均反馈“很有效！”后，进入“我的办法”和相同原因的策略推荐。“有点意思”、失败和没试不计入；单条尝试不能重复验证。自建方法仍可主动反复试用。

退出引导会保留草稿，首页可继续；开始其他场景会替换未确认草稿。复用的确认页展示适用原因，确认后创建新的独立尝试。

## 数据与边界

只在当前浏览器保存，不联网生成内容、不上传记录。不同浏览器、设备或网址来源之间不共享数据；`localhost` 和 `127.0.0.1` 也分别保存。旧版本本地历史会保留；清除浏览器数据后会成为首次使用；“我的记录”提供二次确认清空。

- `zd_history_v1`：行动、原因路径、反馈、父记录、策略版本及计时截止时间。
- `zd_strategies_v1`：由历史重建的策略统计。
- `zd_profile_v1`：首次访问、行动次数和流程草稿（兼容旧解锁字段）。
- `zd_methods_v1`：独立保存的自建方法，包含场景、原因与可选计时。

存储不可用会提示，仍可在本次会话使用。页面内的计时结束不自动认定行动有效。应用不提供医疗诊断，也不会要求通过少吃、额外运动或自责补偿。

## 代码与验证

- `src/data.ts`：五场景问题树、原因框架、支持出口、预设动作。
- `src/model.ts`：记录、推荐排序、反馈版本、存储与计时。
- `src/main.tsx`、`src/styles.css`：页面、交互、响应式界面。
- `src/model.test.ts`：图结构完整性及核心逻辑测试。

使用 React、TypeScript、Vite、Phosphor 图标。双搭子插画由 CSS 绘制；所有视觉资源随应用提供，无外部字体或图片依赖。

普通局域网 HTTP 预览无需 HTTPS：记录 ID 兼容没有 `crypto.randomUUID()` 的环境。

浏览器回归：安装 Playwright 的 Chromium 后运行 `npm run test:browser`。可通过 `TEST_BASE_URL` 指定已运行的预览地址、`BROWSER_EXECUTABLE_PATH` 指定本机浏览器；测试使用独立上下文，不读写用户浏览器记录。
